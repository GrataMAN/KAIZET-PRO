# KAIZET PRO

Конструктор развёрток КЗТО для браузера. Поддерживает столы СРП, двери и мойки. Мойки собраны в одном пункте с выбором типа и количества секций.

Для локального запуска откройте index.html в браузере. Для мобильной ссылки используйте GitHub Pages из корня ветки main.

Кнопка «Поделиться DXF» открывает системное меню, если браузер может передать файл этого формата. В меню можно выбрать почтовое приложение. Если передача вложения недоступна, программа скачивает DXF и предлагает открыть почту, где файл можно прикрепить вручную.

Расчёт и подготовка DXF выполняются в браузере. Произвольные размеры проверяйте по фактическим деталям перед изготовлением.
